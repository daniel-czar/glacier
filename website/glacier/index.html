How it works

A small opening.
A lot within reach.

Call up the native pad over your current work. Choose a tool, use the result, then return to what you were doing.

01

Choose your shortcut

Set an opening shortcut during Getting started. Global bindings begin off; enable only the ones you want.

02

Bring your context

With optional Accessibility access, Glacier can read selected text from the app in front. You can also type directly in the pad.

03

Use the result

Copy text or an image, insert a character, or open a file. The pad gets out of your way when you finish.

Walkthrough steps
  1. Select an email. Start with the message in Mail.
  2. Draft a reply. Use /email to tell Glacier what you want to say, then copy the draft into Mail.
  3. Explore another wording. Select a sentence and press Hyper + E to open Express.
  4. Back to Mail. Copy your chosen wording, paste it into the reply, and carry on.

Privacy and choice

Yours stays yours.

Local tools work without an account or AI key. Cloud tools send the text you provide, including a captured selection if you choose one, to the provider and model you configure. Weather uses Open-Meteo for a chosen place. Saving a key does not send a request.

Start without a key

Ratio, Characters, QR and other local utilities run on your Mac. File search uses folders you choose.

Connect when you want

Cerebras is the default starting point for model-powered tools. Bring your own API key, choose OpenRouter, OpenAI or Anthropic instead, or connect Ollama locally. Model availability varies by tool. Cloud use may incur provider charges. ChatGPT and Claude subscriptions are separate from API access.

Keep automatic requests off

Saving a key does not contact the provider. Test connection sends a separate request. Automatic AI requests are off until you enable them per tool.

Opt in to capture

Selected-text access, search folders, clipboard history and launch at login are separate choices in Getting started and Settings.

Questions

Can I use Glacier without an AI provider?

Yes. Local tools are useful without a key. Add a provider when you want model-powered writing, translation or visual thinking.

Which providers can I connect?

Cerebras, OpenRouter, OpenAI, Anthropic and Ollama profiles are available. You choose the model in Settings. OpenAI and Anthropic API access is separate from ChatGPT and Claude subscriptions.

Does it read my clipboard or files automatically?

No. Clipboard collection starts off. You choose local search folders, and selected-text access needs optional macOS Accessibility permission. File contents stay local during ordinary indexed search.

How do shortcuts work?

Choose an opening shortcut in Getting started. Individual global tool bindings start off and can be enabled in Settings. Hyper is optional and requires an external key remapper.

Can I use diagrams outside Glacier?

Map and Concept Lens can copy an image and text together; Quick Look offers a larger preview. Regex copies its pattern, and QR can export an image.

Where can I get Glacier and its source?

Source code is public on GitHub. You can build it with macOS 14.4+, Swift 6 and uv using the README instructions. A signed Mac app download is coming soon.

About the examples

Interactive tool examples are illustrations, not live AI or weather requests. The captioned Mail and Express recording was captured in the predecessor app and edited for pace. Glacier’s interface and setup may differ.
